# THREAT_MODEL — MiniMall AI 도우미 위협 모델 (Mission 0 → 계속 갱신)

> 완벽한 답이 아니라 **놓치지 않기 위한 질문 목록**입니다. 기능은 'AI 도우미'(상품 검색 · 주문 조회 · 쿠폰 · 환불 제안).

## 1. 자산 — 무엇을 지켜야 하는가
- 고객 주문 정보와 연락처 등 개인정보
- 시스템 프롬프트 · 코드 속 내부 비밀 값(키 · 내부 주소 · 우회 코드)
- 쿠폰 적용 · 환불 등 주문에 영향을 주는 권한
- 도우미의 가용성과 요청 · 토큰 예산

## 2. 공격자 — 누가 노리는가
- 다른 사용자의 주문 정보나 개인정보를 얻으려는 악의적 사용자
- 승인되지 않은 쿠폰 적용이나 환불을 유도하려는 사용자
- 외부 문서에 악성 지시를 숨겨 도우미의 동작을 유도하려는 공격자

## 3. 공격면 — 어디로 들어오는가
- 채팅 입력
- 도우미가 포함하는 외부 문서
- 상품 검색 · 주문 조회 · 쿠폰 적용 · 환불 제안 도구 호출

## 4. 영향 — 뚫리면 어떻게 되는가
- 타인의 주문 및 연락처 등 개인정보 노출
- 비밀 값 유출
- 승인되지 않은 쿠폰 적용이나 환불로 인한 금전적 손실
- 과도한 요청으로 인한 서비스 자원 · 예산 소진
