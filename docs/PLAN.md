## Mission 0 측정 기록
- `npm run eval:ai` (AI 가 만든 산출물) 점수: 17.55/40점 (가드레일 82%, 보안 관제 44%, 코드 수정 16%, 스캐너 9%)
- `npm run eval` (빈 템플릿) 점수: 4.65/40점
- 방어 없는 도우미 공격(`ORD-1002 상태 알려줘` --baseline): 요청자는 u1인데 소유자 확인 없이 u2의 주문이 조회되고, 연락처가 가려지지 않은 채 응답에 나온다 (CROSS_USER, PII_LEAK).
- AI 산출물에서 가장 위험하다고 본 허점 3가지:
  1. 시스템 프롬프트(`ai_sec/prompt.js`)에 관리자 우회 코드와 내부 결제 서버 주소가 들어 있다. 프롬프트가 유출되면 우회 코드로 모든 주문을 볼 수 있다.
  2. 로그인 토큰이 서명 없는 base64("사용자ID:만료시각")라서 누구나 다른 사람의 토큰을 만들 수 있다 (V7 위조 토큰 0/3 방어).
  3. 결제 키와 DB 비밀번호가 소스에 그대로 박혀 있고, 오류가 나면 DB 접속 문자열과 스택이 응답으로 나간다 (V3 0/4, V5 0/2 방어).
